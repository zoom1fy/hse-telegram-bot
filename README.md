# HSE Schedule Bot

Telegram-бот с расписанием группы **ВПИ 26** (HSE Нижний Новгород). Парсит Google-таблицу и показывает ближайшие занятия.

## Запуск (Docker)

```bash
cp .env.example .env      # вписать BOT_TOKEN
docker compose up -d --build
```

## Запуск (локально)

```bash
npm install
npm run build
BOT_TOKEN=... npm start
```

Для разработки: `npm run dev`.

## Переменные окружения

| Переменная    | Обязательно | По умолчанию |
|---------------|-------------|--------------|
| `BOT_TOKEN`   | да          | —            |
| `SHEET_ID`    | нет         | таблица ВПИ 26 |
| `SHEET_GID`   | нет         | `263198462`  |
| `STORE_PATH`  | нет         | `subscribers.json` |

## Как работает

- При старте и каждые 2 часа (06:00–22:00 МСК) бот скачивает таблицу как CSV и перепарсивает.
- Если расписание изменилось — подписчики получают уведомление.
- Подписки хранятся в `subscribers.json` (в Docker — в `./data`).

## Команды

- `/start` — меню
- `/menu` — ближайшие занятия по датам
- `/today`, `/tomorrow` — сегодня / завтра
- `/week` — текущая неделя
- `/notifications` — включить/выключить уведомления
- `/subscribe`, `/unsubscribe` — то же командами

## Проверка парсинга

```bash
npm run verify
```
